CONCURRENCY RULES

How It Works

四条并发规则保证偷菜系统的线程安全

synchronized 互斥锁

每个受害者（victim）对应一个锁。同一时间只有一个线程能进入临界区执行偷菜操作，其他线程必须等待锁释放。

01

在家保护机制

如果受害者正在查看自己的农场（viewing own farm），所有偷菜请求都会被拒绝。只有受害者不在家时才能被偷。

02

25% 偷菜上限

每次访问会话（visit → leave → revisit）最多只能偷走成熟作物的 25%。离开再回来算新会话。

03

CountDownLatch 并发测试

两个客户端同时偷菜 — 使用 Promise.all 模拟 CountDownLatch，观察 mutex 如何序列化并发访问。
