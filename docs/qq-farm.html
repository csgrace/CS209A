CONCURRENCY CONTROLS

本演示模拟的并发机制

🔐

synchronized(victim)

同一时间只能有一个线程进入临界区操作 victim 的农场。其他线程必须等待锁释放。

[Thread-X] synchronized(victim) ENTER / EXIT
📊

Session 偷菜上限 25%

每次 "session"（离开再回来）最多偷 25% 的成熟作物。本演示：6 棵成熟 → 最多偷 1 棵。

maxSteal = floor(ripe × 0.25)
⏱️

CountDownLatch

两个客户端同时发起 steal，服务器通过互斥锁保证操作原子性，只有一个能成功。

CountDownLatch(1).await()
🏠

Victim At Home

如果受害者正在查看自己的农场，所有 steal 请求被拒绝。NPC 默认不在家。

if (currentView.get(v) == v) deny()
