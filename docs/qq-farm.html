HOW TO RUN

本地部署指南

在本地运行服务器 + 代理，即可在浏览器内体验完整并发偷菜

1

启动 Java 服务器

cd assignment/assignment2/CS209A_2025Fall_Assignment2-main
mvn compile exec:java "-Dexec.mainClass=org.example.demo.server.Server"
2

启动 WebSocket 代理

pip install websockets
python websocket_proxy.py
3

打开客户端页面

# 直接用浏览器打开本页，或启动本地服务器
python -m http.server 8080 --directory docs
# 然后访问 http://localhost:8080/qq-farm.html
4

运行并发测试

# 打开新终端，运行 ConcurrencyTest
mvn compile exec:java "-Dexec.mainClass=org.example.demo.ConcurrencyTest"
