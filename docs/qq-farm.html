CONCURRENCY CONTROLS

Simulated Java Concurrency Mechanisms

🔐

synchronized(victim)

Only one thread can enter critical section per victim. Others wait for lock release.

📊

25% Session Steal Limit

Each session (visit → leave → revisit) can steal at most 25% of ripe crops.

⏱️

CountDownLatch

Two clients steal simultaneously — server uses mutex for atomic updates.

🏠

Victim-At-Home Protection

If victim views own farm, all steal requests are rejected automatically.
