并发控制机制

🔐 互斥锁 (synchronized)

当小偷 A 正在偷 victim 的菜时，小偷 B 必须等待，直到 A 完成。这模拟了 Java 的 synchronized(victim) 块。

📊 Session 偷菜上限

每次 "session"（偷一次后离开再回来）最多偷 floor(成熟作物 × 25%)。如果有 8 个成熟，最多偷 2 个。

🏠 在家保护

如果受害者正在查看自己的农场（currentView.get(victim) == victim），偷菜请求会被拒绝。

⏱️ CountDownLatch 测试

点击 "⚡ 并发测试" 按钮，系统会：给 victim 种 8 棵成熟作物，然后让 Alice 和 Bob 同时 发起偷菜。观察服务器日志中的临界区 ENTER/EXIT。

玩法指南

  1. 登录 — 输入用户名
  2. 种植 — 点击 "种植" 按钮，再点击空地（-5金币，10秒成熟）
  3. 收获 — 作物成熟后会闪烁，点击 "收获" 再点成熟作物（+12金币）
  4. 偷菜 — 点击 "偷菜" 按钮，选择目标玩家（需先让对方不在家）
  5. 并发测试 — 一键模拟两个小偷同时偷一个农场
提示：点击 "访问玩家" 可以查看别人的农场。先用并发测试看效果是最快的体验方式！

IMPLEMENTATION

这个演示 vs 真实的 Java 实现

🌐 JavaScript 模拟（本页）

  • Mutex.runExclusive() → async 互斥
  • Map → player/farm 映射
  • setTimeout() → 模拟偷菜延迟
  • Promise.all() → 并发请求
  • 浏览器内直接运行

☕ Java 原版（Assignment 2）

  • synchronized(victim) → 线程锁
  • ConcurrentHashMap → 并发安全 Map
  • 多线程 + CountDownLatch
  • ServerSocket 网络通信
  • JavaFX GUI / Socket 客户端
