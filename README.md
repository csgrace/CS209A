## Assignment 2 Demo (QQ farm) 🎮
A small JavaFX game prototype showcasing:
- UI built with `board.fxml` and resource images
- Game logic in `Game.java`, UI events in `Controller.java`, entry point in `Application.java`
- Typical flow: start → validate operations → update board → finish

Tech stack:
- JDK: OpenJDK 22
- JavaFX: `javafx-fxml` 22.0.1, `javafx-controls` 22.0.1
- Build: Maven 3.8.5
